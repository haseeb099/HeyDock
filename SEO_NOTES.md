# HeyDock search implementation and launch

Service content covers managed IT, onsite dispatch, remote staffing, Microsoft 365, networks, backup, cybersecurity, data centres, rollouts, break/fix, IT asset disposal, AV, connectivity, consulting, business software and AI automation. The public homepage leads with on-site IT support and engineer dispatch; software and AI remain linked lower on the page and via their existing URLs.

## Stack

Static HTML/CSS/JS generated by `build.py` + `enrich.py` + `launch.py`. Cloudflare Pages hosts `dist`; `functions/api/enquiry.js` handles enquiry POST. Software catalogue source: `content/catalog.json`.

## Search metadata

Titles/descriptions, canonical URLs, Open Graph, XML sitemap, Organization/WebSite/WebPage/BreadcrumbList structured data, Service markup on service pages, FAQPage markup matching visible answers.

## Public launch

Default/preview builds: `noindex,nofollow` and `robots.txt` Disallow. Production indexing requires:

1. `HEYDOCK_ORIGIN=https://your-final-domain`
2. `HEYDOCK_PUBLIC=1` on the production build only
3. Hosting configured so visitors can open pages without sign-in
4. Enquiry delivery configured and verified
5. Operator/contact disclosures completed as far as required

Verify canonicals, robots and sitemap on the final domain before Search Console / Bing submission. Do not invent offices, reviews, certifications or response guarantees.
